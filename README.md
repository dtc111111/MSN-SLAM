## Summary

This is the code repository for the main algorithm proposed in the paper "MSN-SLAM: Multi-Submap Implicit Neural SLAM with Local-to-Global Loop Closure for Large-Scale Scene Reconstruction".

The main features of the paper and the algorithm include:

- A progressive multi-submap representation of large-scale 3D scenes;
- A hierarchical local-to-global loop closure mechanism for robust viewpoint reconstruction;
- A novel online distillation algorithm for the backend optimization of submaps and global mapping;
- Real-world system integration and onboard validation through handheld mechatronic platforms under complex environments.

## Prerequisites
This code repo has been tested under Pytorch 2.0, CUDA 11.8, and Python>=3.8. 

Downloading Miniconda3 is highly recommended for creating a virtual environment for this project.

Under the root directory of the code repo cloned or downloaded, enter the following bash commands:

```bash
conda create -n ${venv_name} python=<python_version> -y
conda activate ${venv_name}
pip install torch torchvision 
pip install tqdm scikit-image opencv-python configargparse lpips imageio-ffmpeg kornia lpips tensorboard imageio easydict matplotlib scipy==1.6.1 plyfile joblib timm
```

## Run
### Image dataset preprocessing
To preprocess image datasets and get depth maps and optical flow data, run the following commands in bash:
```bash
python scripts/run_flow.py --data_dir ${SCENE_DIR}
python DPT/run_monodepth.py --input_path ${SCENE_DIR}/images --output_path ${SCENE_DIR}/depth --model_type dpt_large
```

The resulting image dataset under ```${SCENE_DIR}``` should have the following minimum structure:

```
${SCENE_DIR}$/
├── images/                  ← original RGB images
├── depth/                   ← raw depth map and text data generated by DPT
├── depth_maps/              ← colored depth maps generated by DPT
├── dpt/                     ← depth data .npz files generated by DPT
├── sparse/                  ← camera data
├── txt/                     ← camera data in .txt format
├── colmap                   ← COLMAP config file
└──  poses_bound.npy          ← ground truth pose and bound information estimated by COLMAP, for pose accuracy evaluation purposes
```

### Training and real-time evaluation
To train and evaluate the model on a given dataset, run the following command in bash:

```bash
python localTensoRF/train.py --datadir ${SCENE_DIR} --logdir ${LOG_DIR} --fov ${FOV}
```
